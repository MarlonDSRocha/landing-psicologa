# Landing page: psicóloga fictícia

Projeto da disciplina de **Web Standards** (Senac EAD): landing page responsiva de uma psicóloga fictícia.

> **Aviso:** projeto acadêmico, com dados fictícios. Nenhum profissional, CRP ou serviço é real. A tag `noindex` é proposital, para que o site não apareça no Google.

## Tecnologias
- HTML5, CSS3, Flexbox e media queries, sem frameworks
- Mapa do Google incorporado (iframe)

## Estrutura de pastas
- `index.html`
- `styles/styles.css`
- `img/`
- `docs/` (protótipo)

## Decisões do projeto
- Mobile-first, HTML semântico e acessibilidade
- Formulário com rótulos, consentimento e aviso para não enviar dados sensíveis
